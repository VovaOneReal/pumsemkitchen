# Меню

Модуль меню позволяет планировать питание по дням: добавлять дни, распределять рецепты по приёмам пищи и отслеживать КБЖУ и стоимость рациона.

Чтобы перейти к меню, выберите пункт меню **Меню**.

## Список меню

На странице отображается список всех ваших меню, сгруппированных по месяцу. Для каждого меню показаны автор, дата создания и период планирования.

Для поиска по названию используйте строку поиска. Нажмите кнопку **Сортировка**, чтобы изменить порядок отображения. Нажмите **Фильтр**, чтобы ограничить список меню конкретным месяцем.

## Создание меню

1. Нажмите кнопку **Создать** в правом верхнем углу.
2. Введите название меню.
3. Нажмите **Сохранить**.

## Переименование меню

На карточке меню нажмите кнопку с иконкой карандаша, введите новое название и нажмите **Сохранить**.

## Удаление меню

На карточке меню нажмите кнопку с иконкой корзины и подтвердите удаление в диалоге.

## КБЖУ и стоимость меню

На карточке меню нажмите **КБЖУ и стоимость**, чтобы раскрыть сводку: суммарные калории, белки, жиры, углеводы и стоимость всего меню.

## Формирование списка покупок из меню

На карточке меню нажмите кнопку с иконкой корзины покупок. Созданный список появится в модуле **Списки покупок**.

## Содержимое меню

Нажмите на название меню, чтобы открыть его содержимое. Здесь отображается сводка КБЖУ и стоимости по всему меню, а также список запланированных дней.

### Добавление дня

1. Нажмите кнопку **Добавить день**.
2. Выберите дату.
3. Нажмите **Добавить**.

Каждая дата может быть добавлена в меню только один раз.

### Удаление дня

Нажмите на карточку нужного дня и используйте кнопку удаления. Вместе с днём удаляются все назначенные на него приёмы пищи с рецептами.

## День меню

Нажмите на карточку дня, чтобы открыть его. На странице дня отображаются приёмы пищи: завтрак, обед, ужин и другие. Для каждого приёма пищи виден список добавленных рецептов с указанием числа порций.

В верхней части страницы показана сводка КБЖУ и стоимости за весь день. Нажмите **КБЖУ и стоимость** на карточке приёма пищи, чтобы увидеть статистику по конкретному приёму.

### Добавление рецепта в приём пищи

Рецепты добавляются в приёмы пищи со страницы рецепта. Откройте нужный рецепт, нажмите **Добавить в меню** и выберите меню, день и приём пищи. Подробнее — в разделе справки **Рецепты**.

### Изменение числа порций рецепта

На карточке рецепта в приёме пищи измените число порций с помощью кнопок «+» и «−». Изменение сохраняется автоматически.

### Удаление рецепта из приёма пищи

На карточке рецепта в приёме пищи нажмите кнопку удаления и подтвердите действие.

## Статистика КБЖУ и стоимости по дням

1. На странице списка меню нажмите кнопку **Отчёт по питанию**.
2. Укажите диапазон дат с помощью полей **От** и **До**.
3. Данные обновятся автоматически: в таблице будут показаны белки, жиры, углеводы, калории и стоимость питания по каждому дню выбранного периода.
4. Нажмите **Показать график**, чтобы отобразить данные в виде диаграммы.
5. Нажмите **Скачать отчёт**, чтобы сохранить данные в файл Excel.
