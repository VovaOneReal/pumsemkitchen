# Рецепты

В модуле рецептов хранятся ваши кулинарные рецепты с ингредиентами, пошаговым приготовлением и информацией о пищевой ценности.

Чтобы перейти к рецептам, выберите пункт меню **Рецепты**.

## Просмотр списка рецептов

На странице отображается список всех доступных вам рецептов. Для поиска по названию используйте строку поиска. Чтобы изменить порядок отображения, нажмите кнопку сортировки и выберите нужный вариант: по названию или по дате создания.

Нажмите на карточку рецепта, чтобы открыть его.

## Просмотр рецепта

На странице рецепта отображаются:

- **Ингредиенты** — список продуктов с указанием количества и единиц измерения, а также примерная стоимость.
- **Пищевая ценность** — КБЖУ на 100 г или на одну порцию блюда. Переключить режим отображения можно с помощью выпадающего списка в заголовке блока.
- **Приготовление** — пошаговое описание процесса приготовления.

Для масштабирования рецепта под нужное число порций используйте кнопки «+» и «−» рядом с полем **Порции** в блоке ингредиентов. Количества ингредиентов и примерная стоимость пересчитаются автоматически.

Нажмите на название ингредиента, чтобы открыть карточку продукта с подробной информацией о пищевой ценности, конвертации и стоимости.

## Создание рецепта

1. На странице списка рецептов нажмите кнопку **Создать**.
2. Заполните поля:
   - **Название** — обязательное поле.
   - **Описание** — краткое описание блюда.
   - **Источник** — ссылка на оригинальный рецепт (необязательно).
   - **Время приготовления** — в минутах.
   - **На количество порций** — базовое число порций, под которое рассчитаны ингредиенты.
3. Добавьте ингредиенты: нажмите **Добавить ингредиент**, выберите продукт, укажите количество и единицу измерения. При необходимости отметьте ингредиент как необязательный или добавьте заметку.
4. Добавьте шаги приготовления: нажмите **Добавить шаг** и заполните описание. Порядок шагов и ингредиентов можно изменить перетаскиванием.
5. Нажмите **Сохранить**.

## Редактирование рецепта

1. Откройте рецепт из списка.
2. Нажмите кнопку **Редактировать**.
3. Внесите изменения.
4. Нажмите **Сохранить**.

## Удаление рецепта

1. Откройте рецепт из списка.
2. Нажмите кнопку **Удалить**.
3. В появившемся окне подтвердите удаление.

## Добавление рецепта в меню

1. Откройте рецепт из списка.
2. Нажмите кнопку **Добавить в меню**.
3. Выберите меню из списка.
4. Выберите день меню.
5. Выберите приём пищи.
6. Укажите число порций.
7. Нажмите **Добавить**.

## Формирование списка покупок из рецепта

1. Откройте рецепт из списка.
2. При необходимости измените число порций в блоке ингредиентов.
3. Нажмите кнопку **Сформировать список покупок**.
4. В открывшемся окне проверьте число порций и нажмите **Сформировать**.

Созданный список покупок появится в модуле **Списки покупок**.
