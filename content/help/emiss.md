# ЕМИСС

ЕМИСС (Единая межведомственная информационно-статистическая система) — государственный портал статистических данных. Сервис позволяет загружать из него актуальные цены на продовольственные товары и использовать их при расчёте стоимости рецептов и меню.

Раздел **ЕМИСС** доступен только администраторам.

## Загрузка данных

Данные из ЕМИСС загружаются в формате SDMX (XML-файл).

1. Перейдите на портал ЕМИСС и найдите нужный набор данных с ценами на продовольственные товары.
2. Скачайте данные в формате **SDMX**.
3. В сервисе перейдите в раздел **ЕМИСС**.
4. Нажмите кнопку **Загрузить данные (SDMX)** и выберите скачанный XML-файл.
5. После загрузки сервис покажет, сколько новых товаров и записей о ценах было добавлено.

Загрузку можно повторять по мере выхода новых статистических данных — дубликаты не добавляются.

## Управление списком товаров

После загрузки все импортированные товары отображаются в таблице. Для каждого товара показаны название, актуальная цена и дата последней записи.

По умолчанию товары не отображаются в форме выбора при редактировании продуктов. Чтобы сделать товар доступным для привязки к продуктам:

1. Найдите нужный товар с помощью строки поиска.
2. Установите галочку в столбце **Показывать в списке?** напротив нужных товаров.
3. Нажмите **Сохранить изменения**.

Снять галочку можно в любой момент — это скроет товар из списка, но не удалит привязку у продуктов, которые уже используют его цену.
